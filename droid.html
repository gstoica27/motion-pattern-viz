DROID — Motion Clips by Task

5 random DROID scenes per task category. Each scene shows both exterior cameras independently, each with its own 2D track overlay (16 subsampled points from the smoothed consensus-gated tracks) and per-object motion-clip timeline. The filter (threshold=0.02, top-20% trimmed, min clip=0.5s) is run separately per camera because each camera file lives in its own OpenCV optical frame (ext1 and ext2 are not in a shared coord system).
